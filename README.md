# 🔐 Password-Generator
A responsive password generator web app that lets users create strong passwords by selecting length, uppercase, lowercase, numbers &amp; symbols. built with vanilla JavaScript.

# 🚀 Features

- Customizable Length: adjust the password length using a convenient slider.
- Character Selection: Choose exactly what goes into your password:
  - ✅ Include Uppercase (A-Z)
  - ✅ Include Lowwercase (a-z)
  - ✅ Include Numbers (0-9)
  - ✅ Include Symbols (!@#$%&*(){}?~)
- Instant Generator: Click a button to instantly generate a new password.
- Mordern UI: A clean, dark-themed card layout that is easy to read.
- Responsive: Works on desktop and mobile devices.

# 🛠️ Tech Stack

- HTML5: Structure of the application.
- CSS3: Styling Flexbox layout, & dark mode aesthetic.
- JavaScript (ES6): Logic for ranndomiization, string manipulation, & event handling.
